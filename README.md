# E-commerce Performance Dashboard

This repository contains a comprehensive dashboard for analyzing e-commerce performance, including sales, customer, and financial metrics. The dashboard is designed to help users gain insights into their e-commerce business by visualizing data trends and performing in-depth analysis.

## Features

- **Interactive Power BI Dashboard**: Visual representation of key e-commerce metrics.
- **SQL Analysis**: Extensive SQL queries used for data extraction and transformation.
- **Datasets Included**: Example datasets are provided for demonstration and testing.
- **Table Schemas**: Reference for raw and processed data tables.

## Repository Structure

- [`analysis.sql`](https://github.com/Manish-2005-glitch/E-commerce-Performance-Dashboard/blob/main/analysis.sql): Contains all SQL queries used for analysis, data manipulation, and preparation.
- [`dashboard.pbix`](https://github.com/Manish-2005-glitch/E-commerce-Performance-Dashboard/blob/main/dashboard.pbix): Power BI dashboard file with all visualization assets and reports.
- [`dataset used/`](https://github.com/Manish-2005-glitch/E-commerce-Performance-Dashboard/tree/main/dataset%20used): Directory containing the datasets used for analysis and dashboard development.
- [`tables/`](https://github.com/Manish-2005-glitch/E-commerce-Performance-Dashboard/tree/main/tables): Contains definitions or samples of data tables leveraged in the analysis.

## How to Use

1. **SQL Analysis**:
   - Open `analysis.sql` with any SQL editor.
   - Run queries against your e-commerce database or modify the scripts for your data structure.

2. **Power BI Dashboard**:
   - Download and open `dashboard.pbix` using [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/).
   - Update dataset connections as required.
   - Interact with the pre-built dashboards to get insights.

3. **Datasets**:
   - The `dataset used` directory contains example data files. Replace or augment them with your real business data as needed.
